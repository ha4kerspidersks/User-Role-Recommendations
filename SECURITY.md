## Reporting a Vulnerability

Security and privacy in identity entitlement analysis are paramount. If you discover a security vulnerability or potential data leakage risk in this repository, please report it privately:

1. **Email:** [subhajit.kar.official@gmail.com](mailto:subhajit.kar.official@gmail.com)
2. **GitHub Security Advisory:** Submit a private vulnerability report via the [Security tab](https://github.com/ha4kerspidersks/User-Role-Recommendations/security/advisories/new).

Please include:
- Description of the vulnerability or data leakage mechanism
- Minimal reproduction steps or sample synthetic JSON input
- Impact assessment on enterprise identity models

We will review reports within 48 hours and coordinate remediation before public disclosure.
